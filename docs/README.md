# ドキュメント

このディレクトリには、音声アシスタントプロジェクトの設計ドキュメントと仕様書が含まれています。

## ファイル構成

### 📋 要件定義.md
プロジェクトの要件定義書です。以下の内容が含まれています：
- **概要**: プロジェクトの目的と対象プラットフォーム
- **機能要件**: 実装すべき機能の詳細
- **非機能要件**: パフォーマンス、セキュリティ、拡張性の要件
- **制約**: 技術的制約と前提条件

### 🏗️ directory.md
プロジェクトのディレクトリ構成とファイル配置の設計書です：
- **ディレクトリ構造**: 各フォルダの役割と配置
- **ファイル命名規則**: 統一された命名ルール
- **モジュール分割**: 機能別のコード分割方針

### 📝 prompt.md
プロジェクト生成時に使用したプロンプトテンプレートです：
- **生成指示**: AIに対する具体的な実装指示
- **要件参照**: 要件定義との連携方法
- **出力形式**: 期待される成果物の形式

### ⚡ bestpractice.md
開発時に従うべきベストプラクティス集です：
- **コーディング規約**: 統一されたコードスタイル
- **ドキュメント作成**: README、CONTRIBUTING等の作成指針
- **CI/CD**: 自動化とテストの方針
- **セキュリティ**: セキュアな開発のガイドライン

## 使用方法

### 新機能開発時
1. `要件定義.md` で要件を確認
2. `directory.md` で適切な配置場所を決定
3. `bestpractice.md` に従って実装

### ドキュメント更新時
1. 変更内容を該当ファイルに反映
2. 関連する他のドキュメントとの整合性を確認
3. プロジェクトルートのREADMEも必要に応じて更新

## 追加予定のドキュメント

- **api.md**: REST API仕様書
- **deployment.md**: デプロイメント手順
- **troubleshooting.md**: トラブルシューティングガイド
