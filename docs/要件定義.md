# 音声アシスタント プロジェクト 要件定義

## 1. 概要
- Windows（GPUあり）、Mac（CPUのみ）、モバイル(iOS/Android)で動作
- オンライン時はクラウドAPI、オフライン時はLMStudio/Ollamaなどローカルモデルを利用
- 日常会話レベルの対話、勉強サポート機能
- 日本語対応、将来的に多言語対応
- 会話履歴をSupabase PostgreSQLに保存
- フロント⇔バックエンド、クラウド⇔ローカル間通信はTLS/JWTで暗号化

## 2. 機能要件
1. 音声入力（マイクキャプチャ）
2. 音声→テキスト変換（STT）
3. テキスト→LLM（会話エンジン）
4. テキスト→音声変換（TTS）
5. 会話履歴管理（CRUD）
6. オンライン/オフライン モード切替
7. GUIアプリケーション：グローバルホットキー／OSフック対応
8. モバイルアプリ：React Native または Flutter

## 3. 非機能要件
- レイテンシ：STT⇄LLM⇄TTSの往復 ≤ 1.5秒（オンライン）
- セキュリティ：通信全体 TLS、認証 JWT
- 拡張性：モデル・API差し替え可能なプラグインアーキテクチャ
- 設計品質：モジュール単位のテストカバレッジ ≥80%

## 4. 制約
- Python と TypeScript を併用
- Supabase をDBバックエンドに利用
- モバイル推論はクラウド経由
